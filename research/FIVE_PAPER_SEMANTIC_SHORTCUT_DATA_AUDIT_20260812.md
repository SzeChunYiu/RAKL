## Audit rule

This audit separates three questions that must not be merged:

1. **implemented architecture** — what the current RAKL runtime/contracts actually enforce;
2. **measured empirical result** — what frozen experiments/receipts have observed;
3. **scientific/novelty authority** — what those measurements license us to claim.

A framework feature can be implemented without being empirically superior. A demoted AI-operator run can be operationally useful without becoming independent external evidence. A repository issue being closed does not imply the scientific coordinate it once requested was obtained.
