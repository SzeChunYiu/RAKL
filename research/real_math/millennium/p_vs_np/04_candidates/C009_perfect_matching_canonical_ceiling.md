# C009 — perfect-matching ceiling for canonical cover complexity

**Status:** PROOF_DRAFT / SOURCE-ALIGNED / NOVELTY_UNRESOLVED

C009 is a structural upper bound for the canonical semi-filter subproblem in route R004. It explains why many dense or pseudorandom complement graphs are poor candidates for obtaining a super-logarithmic **canonical** cover lower bound.

It is not a P-versus-NP solution and is not currently claimed novel.

## Setup

Let `G subseteq [N] x [N]` be a bipartite graph and let

`U = G^c`.

For each edge `e=(u,v) in G`, its canonical semi-filter is generated by the nonempty complement fibres

`A_u = R_u intersect U`,
`B_v = C_v intersect U`.

Write `rho_can(G)` for the minimum number of pairs needed to cover all canonical semi-filters, following Cavalar–Oliveira.

C008 allows every pair to be represented exactly by a three-colouring of `U` into E-only (`P`), H-only (`M`), and overlap (`B`). A row or column has sign `+` when it sees at least one `P` edge and no `M` edge, sign `-` when it sees at least one `M` edge and no `P` edge, and sign `0` otherwise. A canonical `G`-edge is covered exactly when its endpoint signs are opposite and nonzero.

## Theorem C009

If the complement graph `U` contains a perfect matching, then

`rho_can(G) <= ceil(log_2 N)`.

### Proof

Let

`Q = {q_1,...,q_N} subseteq {0,1}^k`,
`k = ceil(log_2 N)`,

be `N` distinct binary words.

Let the perfect matching in `U` be

`D = {d_1,...,d_N}`,

where each row and each column is incident to exactly one matching edge. Assign the distinct word `q_j` to matching edge `d_j`.

For every coordinate `i in [k]`, define a normalized three-colouring of all complement edges by

- `P_i = {d_j : q_j[i]=0}`;
- `M_i = {d_j : q_j[i]=1}`;
- `B_i = U \ D`.

Thus every nonmatching complement edge is placed in the overlap state `B_i` in every coordinate.

Consider any row `u`. Its complement fibre contains exactly one matching edge, say `d_a`. All other complement edges incident to the row are in `B_i`. Therefore at coordinate `i`:

- if `q_a[i]=0`, the row sees one `P_i` matching edge, no `M_i` edge, and hence has sign `+`;
- if `q_a[i]=1`, it sees one `M_i` matching edge, no `P_i` edge, and hence has sign `-`.

So the row's sign word is exactly the binary code `q_a`, under the convention `0=+`, `1=-`.

The same statement holds for every column, using the unique perfect-matching edge incident to that column.

Now take any edge `(u,v) in G`. Let `d_a` be the matching edge incident to row `u` and let `d_b` be the matching edge incident to column `v`.

These matching edges must be distinct. If `d_a=d_b`, that edge would have endpoints `(u,v)` and would lie in `U`, contradicting `(u,v) in G`.

Hence `q_a != q_b`. Since the codes are distinct, some coordinate `i` has `q_a[i] != q_b[i]`. At this coordinate the row and column have opposite nonzero signs. By C008, the canonical semi-filter for `(u,v)` is covered by the `i`-th pair.

Every `G`-edge is therefore covered by one of the `k` pairs, proving

`rho_can(G) <= k = ceil(log_2 N)`.

## Calibration

For `G_NEQ`, the complement `U` is itself a perfect matching. Cavalar–Oliveira prove

`rho_can(G_NEQ) = log_2 N`

when `N=2^n`. Thus C009 is tight on the published calibration family.

## Corollary C009-C1 — necessary obstruction for a super-log canonical target

Any square bipartite graph family satisfying

`rho_can(G_N) > ceil(log_2 N)`

must have complement `G_N^c` with **no perfect matching**.

Therefore route R004 should not spend primary search budget trying to prove a super-log canonical lower bound for complement expanders, random-like graphs, or algebraic families before first checking whether their complements contain a perfect matching.

This is only a filter on the canonical subproblem. Full cover complexity `rho(G,G_{N,N})` can be much larger because it must cover all relevant semi-filters, not only the canonical family. Cavalar–Oliveira prove linear full cover complexity for random bipartite graphs; C009 does not contradict that result.

## Research consequence

The previous R004 search target was too broad. A super-logarithmic canonical construction, if one exists, must exploit **Hall deficiency or another obstruction to a complement perfect matching**.

That creates an immediate tension. Hall deficiency produces a row set `S` with

`|N_U(S)| < |S|`,

so `G` contains the complete bipartite rectangle

`S x ([N] \ N_U(S))`.

Large structured `G`-rectangles may themselves be easy for a three-state pair to cover. The next atomic question is therefore not merely to remove perfect matchings, but to quantify whether Hall-deficient complements can force high canonical cover complexity despite the large rectangles created in `G`.

## Typed residual C009-R1

> Determine whether Hall deficiency can ever increase canonical cover complexity above `ceil(log_2 N)`, or whether every square bipartite graph satisfies a universal `rho_can(G) <= ceil(log_2 N)` bound.

This is now a clean yes/no discriminator for the canonical route.

A proof of the universal upper bound would retire canonical semi-filters as a route to super-log full cover lower bounds while leaving the full cover problem open. A counterexample would identify the first genuinely useful Hall-deficient family for R004.

## Assurance notes

- C009 is an upper bound on a restricted canonical cover problem, not a lower bound on circuit complexity.
- The proof is elementary but requires formalization or independent verification before stronger promotion.
- Novelty is unresolved; the perfect-matching construction must be searched against graph-cover/fusion literature before any new-mathematics claim.
