# C008 — exact finite separation between canonical and full cover complexity

**Status:** PROOF_DRAFT_FINITE_EXACT / COMPUTATIONALLY_VERIFIED / SOURCE_BOUND / NOVELTY_UNRESOLVED

C008 is a finite structural checkpoint for R004. It proves that the canonical semi-filter subfamily can be strictly easier to cover than the full semi-filter family, even for a `3 x 3` bipartite graph.

It is **not** an asymptotic circuit lower bound, is not a P-versus-NP solution, and is not currently claimed novel.

## Source model

Use Cavalar–Oliveira, *Boolean Circuit Complexity and Two-Dimensional Cover Problems*, ECCC TR25-033 (2025).

For a bipartite graph `G subseteq [N] x [N]`, let the ground set be the complement

`U = G^c`.

A semi-filter over `U` is a nonempty upward-closed family of subsets of `U` that does not contain the empty set. A semi-filter is **above** a graph edge `w=(u,v)` when it contains every complement trace generated by a row or column of the ambient complete bipartite graph that contains `w`. For bipartite graphs this forces it, in particular, to contain the complement row fibre and complement column fibre of `w`.

A semi-filter `F` preserves a pair `(E,H)` when

`E in F and H in F  =>  E intersect H in F`.

The full graph cover complexity is the minimum number of pairs such that no semi-filter above any graph edge preserves all of them.

The canonical subproblem keeps only the semi-filter generated by the two complement fibres of each graph edge.

## The graph

Take `N=3` and label the five complement edges

- `a=(0,0)`;
- `b=(0,1)`;
- `c=(1,0)`;
- `d=(1,2)`;
- `e=(2,1)`.

Thus

`U = {a,b,c,d,e}`

and

`G = {(0,2),(1,1),(2,0),(2,2)}`.

The complement row fibres are

- `A_0={a,b}`;
- `A_1={c,d}`;
- `A_2={e}`.

The complement column fibres are

- `B_0={a,c}`;
- `B_1={b,e}`;
- `B_2={d}`.

## Theorem C008

For this graph,

`rho_can(G) = 1 < 2 = rho(G,G_{3,3})`.

Therefore canonical cover complexity can be a strict lower bound on full cover complexity.

## Part I — one pair covers every canonical semi-filter

Set

`E_2 = {a,c,d}`,
`H_2 = {a,b,e}`.

The four graph edges are checked against the exact C005 canonical pair criterion.

### Edge `(1,1)`

`A_1={c,d} subseteq E_2` and `B_1={b,e} subseteq H_2`.

Also `A_1` is not a subset of `H_2`, and `B_1` is not a subset of `E_2`. Hence the pair covers the canonical semi-filter for `(1,1)`.

### Edge `(0,2)`

`A_0={a,b} subseteq H_2` and `B_2={d} subseteq E_2`.

The opposite containments fail, so the pair covers the canonical semi-filter.

### Edge `(2,0)`

`A_2={e} subseteq H_2` and `B_0={a,c} subseteq E_2`, again with the opposite containments failing.

### Edge `(2,2)`

`A_2={e} subseteq H_2` and `B_2={d} subseteq E_2`, with the opposite containments failing.

Thus one pair covers all canonical semi-filters. Since the canonical family is nonempty, zero pairs cannot cover it. Therefore

`rho_can(G)=1`.

## Part II — two pairs cover every full semi-filter

Define

`E_1={a}`,
`H_1={b,d,e}`,

and retain `(E_2,H_2)` above.

Let `F` be any semi-filter above any one of the four graph edges and suppose, for contradiction, that `F` preserves both pairs.

Because `F` is above the chosen graph edge, it contains the relevant row and column complement fibres. Upward closure then implies that both `E_2` and `H_2` belong to `F` in every case:

- for `(1,1)`, `E_2` contains `A_1={c,d}` and `H_2` contains `B_1={b,e}`;
- for `(0,2)`, `H_2` contains `A_0={a,b}` and `E_2` contains `B_2={d}`;
- for `(2,0)`, `H_2` contains `A_2={e}` and `E_2` contains `B_0={a,c}`;
- for `(2,2)`, `H_2` contains `A_2={e}` and `E_2` contains `B_2={d}`.

Preservation of `(E_2,H_2)` therefore forces

`E_2 intersect H_2 = {a}`

to lie in `F`. Hence `E_1={a}` lies in `F`.

For every graph edge, `H_1={b,d,e}` also lies in `F` by upward closure from at least one required fibre:

- `(1,1)` requires `B_1={b,e}`;
- `(0,2)` requires `B_2={d}`;
- `(2,0)` requires `A_2={e}`;
- `(2,2)` requires `A_2={e}` or `B_2={d}`.

Thus `E_1,H_1 in F`. Preservation of `(E_1,H_1)` would force

`E_1 intersect H_1 = emptyset`

into `F`, contradicting the definition of a semi-filter.

Therefore no semi-filter above a graph edge preserves both pairs, and

`rho(G,G_{3,3}) <= 2`.

## Part III — no single pair covers every full semi-filter

It remains to show `rho(G,G_{3,3}) >= 2`.

Consider three semi-filters, represented by their minimal nonempty generators.

### `F_A`

Minimal generators

`{c,d}` and `{b,e}`.

This is the canonical semi-filter above `(1,1)`.

### `F_B`

Minimal generators

`{a}`, `{b}`, `{e}`.

It is above `(2,0)` because it contains `A_2={e}` and contains `B_0={a,c}` by upward closure from `{a}`.

### `F_C`

Minimal generators

`{a}`, `{c}`, `{d}`.

It is above `(0,2)` because it contains `A_0={a,b}` by upward closure from `{a}` and contains `B_2={d}`.

Suppose a single pair `(E,H)` covered all three semi-filters.

Because it covers `F_A`, after swapping the pair if necessary we may assume

`{c,d} subseteq E`,
`{b,e} subseteq H`,
`{c,d} not subseteq H`,
`{b,e} not subseteq E`.

To cover `F_B`, both `E` and `H` must meet the singleton generator set `{a,b,e}`, while `E intersect H` must meet none of those singleton generators. Since `H` already contains `b,e`, the pair intersection condition forces `E` to contain neither `b` nor `e`. Therefore the only way for `E` to belong to `F_B` is

`a in E`,

and then the intersection condition forces

`a notin H`.

Now consider `F_C`. Both sides of the pair must meet `{a,c,d}`, while the pair intersection must meet none of those singleton generators. Since `E` already contains `a,c,d`, the intersection condition forces `H` to contain none of `a,c,d`. But then `H` does not belong to `F_C`, contradiction.

The swapped orientation of the initial `F_A` assignment is symmetric. Hence no single pair covers all three relevant semi-filters, so

`rho(G,G_{3,3}) >= 2`.

Combining Parts II and III gives

`rho(G,G_{3,3})=2`.

The regression test checks

`rho_can(G)=1`
