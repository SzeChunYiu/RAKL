# C008 — overlap obstruction and exact three-state normal form

**Status:** PROOF_DRAFT / REFUTED_SUBCLAIM_PRESERVED / NOVELTY_UNRESOLVED

This checkpoint sharpens the canonical semi-filter model used in R004. It records one false generalization of the published `G_NEQ` argument and replaces it with an exact normalization that remains valid for arbitrary canonical fibres.

It is not a P-versus-NP solution and is not currently claimed novel.

## Setup

Let `G subseteq [N] x [N]` and `U=G^c`. For a canonical edge `e=(u,v) in G`, define the nonempty complement fibres

`A_u = R_u intersect U`,
`B_v = C_v intersect U`,

and the canonical semi-filter

`F_e = {W subseteq U : A_u subseteq W or B_v subseteq W}`.

By C005, `(E,H)` covers `F_e` exactly when one of the two orientations holds, for example

`A_u subseteq E`, `B_v subseteq H`, `A_u not subseteq H`, `B_v not subseteq E`.

## Refuted subclaim C008-X1 — overlap deletion is not valid for arbitrary fibres

The `G_NEQ` proof in Cavalar–Oliveira can delete `E intersect H` because its relevant complement fibres are singletons. The analogous statement for arbitrary canonical fibres is false.

Take

`A={x,y}`, `B={z}`, `E={x,y}`, `H={y,z}`.

Then `A subseteq E`, `B subseteq H`, `A not subseteq H`, and `B not subseteq E`, so `(E,H)` covers the canonical filter generated by `A,B`. But

`E\H={x}`, `H\E={z}`,

and `{x}` no longer contains either complete generator. Thus the disjoint pair does not cover the filter.

This is graph-realizable, for example with target edge `(0,0) in G` and complement edges `x=(0,1)`, `y=(0,2)`, `z=(1,0)`, with no other complement edge in target row 0 or target column 0.

**Consequence:** `E intersect H` can be load-bearing outside the singleton-fibre case. Arbitrary canonical-cover arguments may not silently replace pairs by disjoint pairs or partitions.

## Lemma C008-L1 — union normalization is valid

Let

`N_0 = U \ (E union H)`,
`E' = E union N_0`,
`H' = H union N_0`.

Every canonical semi-filter covered by `(E,H)` is also covered by `(E',H')`.

### Proof

Assume the orientation

`A_u subseteq E`, `B_v subseteq H`, `A_u not subseteq H`, `B_v not subseteq E`.

Because `A_u subseteq E` and `B_v subseteq H`, neither fibre contains an element of `N_0`. Adding `N_0` to both sides therefore preserves the two positive containments and cannot repair either failed opposite containment. The same C005 orientation still holds for `(E',H')`. The other orientation is symmetric.

Thus every pair in a canonical cover may be normalized so that

`E union H = U`.

## Exact three-state representation

For a union-normalized pair, every complement edge has exactly one of three states:

- `P = E \ H`, E-only;
- `M = H \ E`, H-only;
- `B = E intersect H`, both/overlap.

Conversely, every partition `U=P disjoint_union M disjoint_union B` defines

`E=P union B`, `H=M union B`.

The fourth state, neither E nor H, is unnecessary. The overlap state is essential in general.

## Lemma C008-L2 — exact endpoint-sign criterion

For a three-state colouring, define a row sign by its complement fibre `A_u`:

- `+` iff `A_u` has at least one `P` edge and no `M` edge;
- `-` iff `A_u` has at least one `M` edge and no `P` edge;
- `0` otherwise.

Define column signs analogously from `B_v`.

Then a canonical edge `(u,v) in G` is covered by the pair exactly when its row and column signs are opposite nonzero signs, `(+,-)` or `(-,+)`.

### Proof

`A_u subseteq E=P union B` is equivalent to having no `M` edge, while `A_u not subseteq H=M union B` is equivalent to having at least one `P` edge. This is exactly the `+` condition. The other signs and the column case are symmetric. Substitute into C005.

## Computational consequence

The exact canonical-cover oracle need only enumerate `3^|U|` normalized states per candidate pair rather than all `4^|U|` membership states. This is an exact reduction, not a heuristic symmetry quotient.

The regression suite preserves the overlap-deletion counterexample and exhaustively checks C008-L1 on all pairs and all nonempty row/column fibres over a four-element universe.

## Research consequence

The canonical problem is not a partition problem. Its exact local state is a three-colouring in which the `B` overlap may carry most complement incidence while `P` and `M` provide exclusive witnesses.

This normalization is subsequently used by C009, which subsumes the perfect-matching ceiling already merged as C007.
