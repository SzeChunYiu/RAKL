# C019 — quadratic-residue difference family passes the C018 high-rank admission screen

**Status:** `CANDIDATE_FAMILY_SCREEN_PASS / GF2_RANK_PROOF_DRAFT / COVER_LOWER_BOUND_OPEN / NO_NOVELTY_CLAIM`

C019 attacks O9d11 after C018. The purpose is not to claim a cover lower bound. It is to construct a concrete explicit family that clears the cheapest necessary high-rank and compression screens before any expensive full-cover lower-bound search.

## Object

Let `p` be a prime with

`p == 3 (mod 8)`.

Let `Q_p` be the nonzero quadratic residues in `Z_p`. Define the square bipartite graph `QR_p` with left and right vertex sets both equal to `Z_p` by

`(x,y) in QR_p  iff  y-x in Q_p`.

As a directed relation on a single copy of `Z_p`, this is the ordinary Paley-tournament relation. We use two copies of the vertex set so it fits the R004 square bipartite graph-complexity object.

The family is explicit. Infinitely many admissible primes exist by Dirichlet's theorem for the progression `3 mod 8`; the rank proof below is pointwise for every admissible prime and does not depend on how the primes are enumerated.

## Theorem C019-L1 — full GF(2) adjacency rank for p == 3 mod 8

Let `A_p` be the `p x p` adjacency matrix of `QR_p`, interpreted over `GF(2)`. Then

`rank_GF(2)(A_p) = p`.

In particular the C018 rank screen is maximally passed:

`rank_GF(2)(A_p) = N = omega(log N)`.

### Proof

Let

`a(X) = sum_{q in Q_p} X^q in GF(2)[X]`.

The matrix `A_p` is the circulant convolution matrix generated by the coefficient vector of `a`. A circulant of order `p` is invertible over `GF(2)` exactly when

`gcd(a(X), X^p-1) = 1`.

Because `p` is odd, `X^p-1` has no repeated roots in an algebraic closure of `GF(2)`. It is therefore enough to show that `a` is nonzero at every `p`-th root of unity.

At `X=1`,

`a(1) = |Q_p| mod 2 = (p-1)/2 mod 2 = 1`,

because `p=8k+3` makes `(p-1)/2=4k+1` odd.

Now let `omega != 1` be a primitive `p`-th root of unity in the algebraic closure, and write

`eta_Q = sum_{q in Q_p} omega^q`,
`eta_N = sum_{n in N_p} omega^n`,

where `N_p` is the set of quadratic nonresidues.

For `p == 3 (mod 8)`, the standard supplementary law for the Legendre symbol gives `(2/p)=-1`, so multiplication by `2` sends `Q_p` bijectively onto `N_p`. In characteristic two, Frobenius squaring therefore gives

`eta_Q^2 = sum_{q in Q_p} omega^(2q) = eta_N`.

Also

`eta_Q + eta_N = sum_{j=1}^{p-1} omega^j = 1`,

because `1 + omega + ... + omega^(p-1)=0` and `-1=1` in characteristic two. Consequently

`eta_Q^2 + eta_Q + 1 = 0`.

Thus `eta_Q` is nonzero, and `eta_N=eta_Q^2` is nonzero as well.

For any nontrivial `p`-th root `omega^s`, multiplication of exponents by `s` either preserves `Q_p` or swaps `Q_p` and `N_p`. Hence

`a(omega^s)` is either `eta_Q` or `eta_N`, and is never zero.

So `a` and `X^p-1` have no common root. The circulant is invertible and `rank_GF(2)(A_p)=p`.

## Theorem C019-L2 — no smaller pullback quotient through repeated rows or columns

All `p` rows of `A_p` are distinct, and all `p` columns are distinct.

### Proof

Suppose two rows indexed by `x != x'` were equal. Translating the row condition gives

`Q_p = Q_p + (x-x')`.

A nonzero translation generates the full additive group `Z_p`, since `p` is prime. Repeated translation would force `Q_p` to be either empty or all of `Z_p`, contradicting `|Q_p|=(p-1)/2`. The column argument is identical.

Therefore any C018-style pullback representation through maps

`lambda_L:Z_p -> [K]`, `lambda_R:Z_p -> [K]`

must have both maps injective if it represents the graph exactly. In particular it cannot compress `QR_p` to a base graph with `K<p` merely by identifying left or right vertices.

This does **not** rule out a different small-cover construction. It rules out only the direct arbitrary-pullback compression adversary registered by C018.

## Density screens

Every left and right vertex has degree

`Delta = (p-1)/2`.

The bipartite graph has

`E = p(p-1)/2`

edges on `2p` vertices. Hence any partition of its edge set into forests needs at least

`ceil(E/(2p-1)) = Omega(p)`

forests, by the elementary fact that a forest on `2p` vertices has at most `2p-1` edges.

Consequences for the existing R004 adversaries are deliberately narrow.

- C014's bounded-degree ceiling is not logarithmic here because `Delta=Theta(p)`.
- C015's constant-arboricity ceiling is not logarithmic here because even the density lower bound on arboricity is `Omega(p)`.
- C018's low-rank ceiling is not logarithmic here because the rank is exactly `p`.
- C013's obvious twin/quotient compression is unavailable because all rows and columns are distinct.

These statements do not prove high cover complexity.

## Screens not yet discharged

The following are still open and are the reason C019 is only a candidate-family screen pass.

1. **Cyclic/intersection upper bound.** The source theorem `rho <= D_intersection` means any unexpectedly small intersection construction kills the candidate. Quadratic residuosity is efficiently evaluable by modular arithmetic, so a polylogarithmic upper bound is plausible. The next pass must compile the cheapest source-valid construction and determine whether it is merely `poly(log p)` or actually `O(log p)`.
2. **Finite-state/generalized aggregation.** C016 does not apply directly with a fixed state set independent of `p`; a straightforward modular evaluator has a state space growing with `p`. This is not a proof that no different fixed-state representation exists.
3. **Population/XOR symmetry.** C017 applies to arbitrary symmetric functions of coordinatewise binary XOR on side size `2^t`. `QR_p` is an additive Cayley relation on the odd prime group `Z_p`, not a binary-XOR relation. This only says C017's stated theorem does not directly discharge the family.
4. **Pair reuse / character structure.** Translation symmetry and multiplicative characters may permit a cover construction that is invisible to rank, degree, or arboricity. This is the highest-priority adversarial search.
5. **Power-of-two transference.** R004 Boolean encoding is cleanest for side size `2^n`. Any eventual lower bound on the prime-size family needs an exact restriction/padding/transference lemma before root-level circuit consequences are stated.

## Counterexample-first executable checks

`05_falsification/quadratic_residue_rank_screen.py` constructs `A_p` exactly and reports

- degree and edge count;
- exact `GF(2)` row rank;
- number of distinct rows and columns;
- additive translation stabilizer of the residue set;
- the elementary density lower bound on forest-partition count.

Regression tests check primes `3, 11, 19, 43, 59`, all congruent to `3 mod 8`. They verify full rank and the no-translation-compression certificate. These finite computations validate the implementation and examples only. They do not prove the asymptotic theorem.
