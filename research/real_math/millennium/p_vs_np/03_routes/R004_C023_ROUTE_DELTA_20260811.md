# R004 route delta — C023 spectral-ratio no-go

**Date:** 2026-08-11  
**Authority:** route control only

## Atom attacked

`O9d12a2a` asked for a reuse-stable / cyclic-fusion-stable invariant capable of proving super-logarithmic cover complexity on an explicit target.

The first candidate family inherited from C022 was a monotone invariant based only on Lokam's scalar spectral hardness parameter

`r(G)=N/||A_G||`.

C023 retires this family completely for unrestricted cover complexity.

## Why it fails

Every `N x N` sign matrix satisfies `r(G)<=sqrt(N)`. The mod-2 inner-product graph on `N=2^t` vertices per side attains equality because its sign matrix is Walsh-Hadamard. Yet merged C012 gives

`rho(IP_t)<=3t-2=O(log N)`.

Therefore any universal lower-bound rule `rho(G)>=F_N(r(G))` with `F_N` nondecreasing is bounded by `O(log N)` on **every** graph. No amount of sharpening the scalar operator-norm estimate can turn this template into the super-logarithmic R004 invariant.

## Search-control update

### Retired

- top-singular-value / operator-norm ratio as a standalone monotone cover lower-bound measure;
- any monotone scalar reparameterization of `N/||A_G||` without extra graph structure.

### Still viable

1. a non-scalar matrix invariant using more of the singular/eigenvalue profile;
2. a spectral invariant conditioned on a separately justified structural property that excludes the inner-product graph and is itself compatible with cyclic fusion;
3. semi-filter/cyclic-construction quantities defined directly on preserving filters rather than on the final adjacency matrix;
4. constructive gate-elimination style invariants that track how reuse changes under simplification;
5. the parallel upper-bound attack O9d12a1 on QR.

## Next discriminator

A parallel literature lane should compare this requirement with 2026 constructive/convergent gate-elimination work, but those results must not be conflated with a cover lower bound until an exact translation to the R004 cyclic model is proved.
