# R004 route delta after C010

**Date:** 2026-08-10  
**Authority:** route-control update only

## Result

C010 gives a proof-draft upper-bound obstruction for block-diagonal complement sums. Define `sigma(G)` as the minimum number of **disjoint** pairs that generator-separate every graph edge admitting a semi-filter above it. The source Definitions 18–21 immediately give

`rho(G,G_{N,N}) <= sigma(G)`.

For the `t`-fold block-diagonal complement sum of a base graph `G_0`, local disjoint pairs can be multiplexed across all copies, while `ceil(log_2 t)` binary block-separation pairs handle cross-block graph edges. Therefore

`rho(G_0^{boxplus t}) <= sigma(G_0) + ceil(log_2 t)`.

The merged C008 gadget has an explicit two-pair disjoint generator-separating cover, so `t` isolated copies satisfy

`rho <= 2 + ceil(log_2 t)`.

## Route consequence

The naive fixed-gadget direct-sum composition opened after C008 is retired. Repeating a finite separator in isolated blocks does not produce a super-logarithmic explicit family.

## Active successor O9d2

A surviving composition must alter the complement across coordinates strongly enough that global pair multiplexing no longer works. Candidate families must therefore be **coupled** rather than block diagonal, for example tensor/product constructions with cross-coordinate complement constraints.

Every candidate will first face an upper-bound adversary using:

1. disjoint generator-separating pairs;
2. binary/low-dimensional coordinate codes;
3. multiplexing of local pair families;
4. non-disjoint overlap reuse;
5. restrictions/projections back to simpler graph families.

Only a construction surviving these upper-bound attacks deserves asymptotic lower-bound proof budget.

## Scope

C010 does not refute full graph cover complexity as a route. The primary source proves random graphs have linear full cover complexity, so hard objects exist non-explicitly. C010 only says fixed isolated gadget repetition cannot explain that hardness.
