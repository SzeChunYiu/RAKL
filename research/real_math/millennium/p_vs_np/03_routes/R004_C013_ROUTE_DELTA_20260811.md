# R004 route delta after C013

**Date:** 2026-08-11  
**Authority:** route-control update only

## Result integrated

C013 tests the first O9d5 code/syndrome family opened after C012. It proves a general quotient obstruction.

Let `Q` be a non-trivial bipartite quotient graph and let `G` be obtained by replacing each left and right quotient vertex by a nonempty class of twins, with adjacency determined only by the quotient labels. Then

`rho(G) <= rho(Q)`.

The proof lifts an optimal quotient pair family. Any blow-up semi-filter preserving every lifted pair pushes down to a quotient semi-filter preserving the original family, contradicting the definition of quotient cover complexity.

## Consequence for linear syndrome graphs

For a binary matrix `H` of rank `k`, both natural syndrome relations collapse to quotient graphs on the `2^k` syndrome classes.

- `Hx != Hy` is a blow-up of `G_NEQ`, hence `rho <= k` by source Proposition 40.
- `Hx = Hy` is a blow-up of equality on `k`-bit labels. A direct intersection construction gives quotient `D_intersection <= 2k-1`, hence `rho <= 2k-1`.

Thus parity-check density, code distance, or other sophistication of the linear code cannot create a super-logarithmic cover lower bound when graph adjacency depends only on the syndrome labels. The cover model sees the quotient relation rather than the bit-level cost of computing the labels.

## Upper-bound adversary strengthened

Every future R004 candidate must now face the following order of attacks before asymptotic lower-bound work.

1. **Twin / identical-neighbourhood quotient compression.** Collapse row and column vertices with identical graph neighbourhoods and upper-bound the quotient cover complexity.
2. **Exact tiny cover search.** For the surviving quotient on tractable sizes, compute exact full cover complexity and search for unexpectedly reusable pairs.
3. **Source-level intersection / cyclic construction.** Build the strongest explicit `D_intersection` or cyclic-construction upper bound for graph membership and transfer it to `rho` through the primary source.
4. **Pair multiplexing / generator separation.** Search for explicit pair families that reuse across blocks, coordinates, or structural classes.
5. **Only then lower-bound search.** A family that already has `O(log N)` from any earlier step is retired as a super-log cover target.

## New active atom O9d6

Move to nonlinear globally correlated graph families with load-bearing variation inside every natural quotient block. A useful candidate should have many distinct row and column neighbourhood types and should not reduce to a small-label relation whose quotient is already easy.

Candidate generators include nonlinear code correlations, pseudorandom algebraic relations, incidence relations, and explicit extractor/disperser-style predicates, but each must first pass the quotient and `D_intersection` upper-bound screens. No candidate is favored merely because its defining formula looks algebraically complicated.
