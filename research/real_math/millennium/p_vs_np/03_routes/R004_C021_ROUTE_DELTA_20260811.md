# R004 route delta after C021

**Date:** 2026-08-11

## Atom attacked

C020 residual O9d12a. Replace the elementary repeated-squaring `O((log p)^3)` adjacency construction by the best source-bound Jacobi-symbol algorithm plus a machine-to-circuit simulation.

## Result

Let `n=ceil(log2 p)`. Brent–Zimmermann compute the Jacobi symbol in `O(M(n) log n)` time. Harvey–van der Hoeven give `M(n)=O(n log n)` in the multitape Turing model. Hence the Jacobi predicate has machine time

`T_J(n)=O(n log^2 n)`.

Pippenger–Fischer convert `T` steps of a machine with one-dimensional tapes into a combinational logic network of cost `O(T log T)`. Therefore the Jacobi predicate has bounded-fanin Boolean circuit size

`O(n log^3 n)`.

For prime `p`, the Legendre symbol is the Jacobi symbol with denominator `p`. After computing `d=y-x mod p`, adjacency in `QR_p` is exactly `Jacobi(d,p)=+1`; `d=0` gives symbol zero and is not an edge. Translating the Boolean network to a fixed De Morgan basis and applying the C020 dual-rail set compiler gives

`D_intersection(QR_p | G_{p,p}) = O(n log^3 n)`

and therefore

`rho(QR_p,G_{p,p}) = O(n log^3 n) = O(log p * (log log p)^3)`.

## Research consequence

C021 shrinks the Paley-family full-cover window from cubic in `log p` to nearly linear in `log p`, up to a polylogarithmic factor in the bit length. It still does **not** refute `rho(QR_p)=omega(log p)`, because `(log log p)^3` diverges.

The route is now sharply constrained. Any super-log lower bound for this family would have to live inside a very narrow asymptotic window between `omega(log p)` and `O(log p (log log p)^3)`.

## Explicitness tension exposed

The C020/C021 compilation also yields a generic screening rule. If a bipartite graph family on `N x N` vertices has an adjacency predicate with De Morgan circuit size `s(log N)`, then its graph intersection complexity and cover complexity are at most `O(s(log N))`.

Consequently, any candidate family whose adjacency already has an `O(log N)` Boolean circuit cannot possibly witness a super-logarithmic cover lower bound. O9d12c is therefore revised: do not search merely for high-rank strongly explicit graphs; first measure the adjacency-circuit ceiling.

This does not make R004 circular. A family with polylogarithmic but superlinear-in-`log N` adjacency complexity can still, in principle, support a super-log cover lower bound. But standard algebraic families with very cheap adjacency tests are adversarially suspect from the start.
