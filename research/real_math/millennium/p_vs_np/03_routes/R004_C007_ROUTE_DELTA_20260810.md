# R004 route delta after C007

**Date:** 2026-08-10  
**Authority:** route-control update only

C007 changes the canonical-cover search policy.

## Retired canonical targets

If the complement `U=G^c` has a perfect matching, C007 constructs a canonical cover of size at most `ceil(log2 N)`. Therefore regular balanced bipartite complements, including ordinary regular expander/Cayley candidates, cannot beat the NEQ logarithmic baseline through the canonical semi-filter subfamily.

This does not upper-bound full graph cover complexity or graph intersection complexity.

## New discriminator

Before allocating asymptotic proof-search budget to a canonical candidate family, first run a Hall/perfect-matching audit. A perfect matching closes that canonical super-log route immediately.

## Successor lanes

1. **Hall-deficient canonical lane.** Search explicit complements with controlled Hall deficiency and test whether canonical cover can exceed `log N`.
2. **Full-cover lane.** Implement the smallest exact full semi-filter cover oracle and search for explicit families where the full cover measure remains large even though the canonical subfamily has a logarithmic cover.
3. **Canonical insufficiency theorem.** Try to generalize C007 to a wider structural ceiling. A strong enough ceiling would be valuable negative knowledge because it would redirect the source transference program away from the canonical subfamily entirely.

The full-cover lane is now the preferred R004 successor because it survives the C007 obstruction and remains directly tied to Cavalar–Oliveira's unrestricted-circuit transference framework.
