## Atom attacked

C016 opened O9d9 by requiring growing aggregation-state or local-symbol complexity. The first proposed successor fiber was a Hamming/sum constraint with a modulus growing with the coordinate count.

C017 refutes that entire symmetric-Hamming fiber. The state count of the obvious automaton is the wrong complexity coordinate because population count gives a different representation.

## New upper-bound adversary

For arbitrary symmetric `S_t:{0,1}^t->{0,1}`, define

`G_t(x,y)=S_t(x XOR y)`.

C017 constructs coordinate XOR bits and complements, computes their binary Hamming weight with a complement-carrying linear-size full-adder network, decodes all exact weight classes with a linear-size prefix tree, and freely unions the classes accepted by `S_t`.

The resulting conservative bound is

`rho(G_t) <= 80 t = 80 log2 N`.

The constant is intentionally unoptimized.

This kills, as super-logarithmic R004 targets, every exact Hamming-distance relation, Hamming ball/threshold, arbitrary union of Hamming shells, and every growing-modulus residue condition.

## Prior-work sanity check

The underlying fact that every symmetric Boolean function has linear ordinary Boolean-circuit size is classical. A primary journal reference is Demenkov, Kojevnikov, Kulikov and Yaroslavtsev, Information Processing Letters 110(7), 264–267 (2010), DOI `10.1016/j.ipl.2010.01.007`, whose abstract gives `4.5n+o(n)` circuits for arbitrary symmetric functions.

C017 makes no novelty claim. The RAKL-specific proof draft explicitly carries complements so the construction is valid in the source intersection-complexity accounting without treating NOT of an intermediate set as free.
