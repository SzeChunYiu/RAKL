## Functional additions

### Learning progress

For matched competence probes:

\[
LP_t(f)=Q_t(f)-Q_{t-k}(f).
\]

Positive progress can justify persistence; flat repeated equivalent failures trigger strategy switching; negative progress triggers a regression audit. High competence with flat progress on a mastered challenge advances the learning frontier.

### Error attribution before repair

Missing evidence or a measurement/clock failure routes to observation acquisition rather than method invention. An implementation bug routes to code repair. Stochastic/unidentified misses require discrimination rather than immediate self-modification. A supported method-basis gap can route to independent help or constructive invention.

### Independent help

Help receives independent credit only when both process/context and evidence lineage are independent. Same-context critique can inform a strategy switch but is not independent assurance.

### Productive failure

A failed attempt can remain valuable when it creates a new discriminating residual. The controller then routes to a registered challenge that separates surviving causes.

### Anti-rumination

Two or more reflection rounds with no new residual, causal attribution, action-policy change or calibration gain terminate the reflection mode.

### Project dual output

A project failure can emit both:

\[
(e^{science},e^{method}),
\]

which are routed to separate evidence-governed queues. A method repair cannot rewrite the domain negative evidence that motivated it.

## Psychology completeness conclusion

After adding Challenge Learning Control, no obvious high-impact functional psychology category is missing as a prerequisite for launching a controlled real project. The remaining psychology-adjacent questions are empirical:

- learning-progress curriculum value;
- accuracy of failure-cause attribution;
- value/cost of adaptive help seeking;
- timing of persistence versus switching;
- experience-to-procedural-skill consolidation;
- skill retention under environment/model/domain drift;
- fresh cross-model/cross-domain transfer;
- non-redundant value of genuinely independent social review.

The architecture intentionally does not simulate subjective emotion or personality where their research-control functions are already represented by agenda value, resource/risk control, learning progress, revision and help seeking.

## Launch judgement

The framework is now **conceptually launch-ready for the controlled `polymarket_crypto` trial**, not globally saturated or empirically proven complete. Requiring every component to have real-project utility evidence before starting the real project would be circular: the real project is the integration test and challenge curriculum.

Every project failure should therefore be evaluated twice:

1. what does it teach about crypto spot science?
2. what does it teach about RAKL's own research method?

Method changes discovered during the trial remain subject to frozen discriminators, fresh transfer, protected evaluation and negative-history preservation.
