# RFA v1 — parent matrix (frozen 2026-08-15)

Assimilation-first stance: every nearest parent is food. Uniqueness (if any)
lives in the synthesis plus the delta organs, not in overlap avoidance. This
matrix is the frozen parent set for the RFC-v1 utility benchmark arms; it
records each parent's contribution, what RFA assimilates, and the residual
RFA still owes. Cutoff: 2026-08-15 (cutoff-limited nearest-work result, not a
global-novelty proof).

| Parent | Contribution | Assimilated into RFA | Residual RFA owes against it |
|---|---|---|---|
| Rational metareasoning / selecting computations | Computation itself is a decision; effort chosen by expected decision improvement vs cost | Audit scheduling and value-of-audit stopping (STOP_BOUNDED, CANNOT_CHECK at cap) | Not a scientific framework/authority architecture; does not decide when the representation is wrong — that is RFA's question |
| DreamCoder | Reusable symbolic abstraction/language can itself be learned | Framework/representation candidates are learnable, versioned, transferable pursuit objects | No authority boundary or evaluator chronology in parent — RFA adds both |
| SELF-DISCOVER | Compose task-intrinsic reasoning structure from atomic modules | No single reasoning structure is universal; framework is conditional on task structure | Parent accepts the stated task; RFA audits the statement itself |
| LADDER | Recursive downward simplification improves capability | DESCEND is a licensed audit action | Parent lacks upward repair; RFA's ASCEND (≥2 failed local repair families + supported parent challenge) is the delta |
| Select-then-Solve / paradigm routing | Per-task paradigm selection can beat one fixed paradigm | Framework candidates compete under a frozen decision contract | Parent chooses among paradigms; RFA recursively validates formulation/interfaces/evaluator/authority |
| Gödel Agent / Darwin Gödel Machine | Recursive self-modification, empirical descendant selection | Open-ended method search, archive branching (escalation path only) | Benchmark utility is not scientific authority; self-modification does not solve question/framework validity |
| Red Queen Gödel Machine | Fixed evaluator within epoch; evaluator evolution at epoch boundaries | Evaluator change closes the epoch (S04) | No question/framework/decomposition authority semantics in parent |
| BenchGuard | The benchmark/evaluator can be the defective object | EVALUATOR is an auditable coordinate (F7, AUDIT_EVALUATOR outranks all) | Evaluator audit is one coordinate of RFA's full projection, not the whole |
| SciAgentArena / ResearchClawBench / open-ended shadow evals | Well-specified execution ≪ open-ended research judgment; failures include protocol/evidence mismatch, weak backtracking | Paper VI must test formulation/framework revision, not only workflow execution | These are evaluation instruments, not controllers |
| AI-agent-supported research problem formulation | Problem formulation is an explicit AI-supported research stage | Question candidates are typed pursuit objects with receipts | Parent is not a recursive evidence/authority controller |

## Benchmark arm mapping (RFC-v1 design, future freeze)

```text
A DIRECT_SOLVE                      — no-audit null
B STATIC_CURRENT_RAKL               — current stack, fixed formulation
C GENERIC_SELF_REFLECTION           — unstructured self-critique parent
D TASK_REASONING_STRUCTURE_PARENT   — SELF-DISCOVER / select-then-solve lineage
E DOWNWARD_RECURSION_PARENT         — LADDER lineage (descend-only)
F FULL_RAKL_RECURSIVE_FORMULATION   — RFA v1
G ORACLE_RESPONSIBILITY             — known-world only (label leakage control)
```

Positive terminals for RFA require F to beat the strongest parent on
responsible-coordinate localization and correct revision at matched cost,
with zero authority/evaluator violations and a false-reframe rate of 0 on
F0. Negative terminals (STATIC_FRAMEWORK_SUFFICIENT,
REASONING_ROUTER_PARENT_SUFFICIENT, DOWNWARD_RECURSION_PARENT_SUFFICIENT,
FALSE_REFRAME_HARM, EXTERNAL_PARENT_WINS) narrow the architecture and are
reported as first-class outcomes, never relabeled.

## Candidate RAKL synthesis (post-assimilation)

An executor-independent, evidence-governed recursive formulation controller
in which question, framework, decomposition, interfaces, provisional atoms,
measurement and evaluator are typed pursuit objects; descendant failures can
reopen the lowest responsible ancestor; revision is separated from
scientific authority; and closure is target/evaluator/cutoff relative.

No invention claim over: metareasoning, recursive decomposition, abstraction
learning, reasoning-strategy selection, self-improving agents, benchmark
auditing, research problem formulation, or evaluator co-evolution.
