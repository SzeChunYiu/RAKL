# Definition of done

## Integration closure

All must hold:

- live base/head explicitly recorded;
- every handoff item assigned `ON_MAIN`, `MERGED`, `SUPERSEDED`, `REJECTED`, or `GATED`;
- no stale file blindly overwrites stronger current-main behavior;
- exact-base blob-bound guard edits applied or manually reconciled;
- full-repository regressions for structural/TCSQ/authority-lineage guards pass;
- focused new tests pass;
- full repository suite passes;
- current repository audits pass;
- deterministic experiment/artifact gates pass;
- relevant paper sources/figures build and are visually inspected;
- no legacy identity silently changes;
- no derived/learned/search object gains scientific authority;
- every integrated experimental epoch has one cross-surface manifest with resolved required receipts;
- all P0/P1/P2 code gaps found by the integration audit are either fixed or explicitly open with failing gate.

## Scientific closure is separate

The implementation is **not** scientifically complete merely because integration closure passes.

Each research lane closes only through its own preregistered falsifier/comparator:

- TCSQ net-cost claim;
- neural quotient residual;
- directional witness residual;
- learner-conditioned signal;
- adaptive allocation residual;
- shared-identity residual;
- VTG local navigability;
- natural dynamics residual;
- cognitive compilation residual;
- matched end-to-end workflow result.

## Independent assurance

Same-context expert simulation earns no independent-review credit. Mathematical, security and domain/scientific external review remain separate closure coordinates.
