# Epistemically governed cognitive compilation — preregistration

## Candidate mechanism

```text
external RAKL residual
-> typed diagnosis + frozen discriminator
-> structural training proposal
-> bounded challenger model update
-> fresh disjoint assurance
-> model promote / reject / narrow
-> challenger returns to external RAKL
```

## Noninterference invariant

Training-only transition must preserve the scientific authority projection:

```text
pi_epi(before) == pi_epi(after_training)
```

Model improvement may later help propose new experiments/evidence, but it cannot itself mint scientific authority.

## Strong parents / controls

- no weight update;
- generic failure-example fine-tuning;
- generic reflection + distillation;
- textual skill → LoRA/adapter compilation;
- random matched update;
- static RAKL structural fine-tuning without typed diagnosis.

## Fresh-assurance requirements

- assurance split disjoint from proposal/training split;
- evaluator identity distinct from proposer;
- frozen metric and promotion threshold before fresh outcomes;
- negative/failed update history retained;
- incumbent model remains available for rollback;
- promotion is model-governance authority only.

## Positive claim

A RAKL-specific residual requires that typed structural diagnosis/governance improves fresh performance or safety relative to the strongest faithful parent under matched data/compute without increasing unauthorized authority movement.
