# Novelty and prior-art boundary

## Anti-claims

Do not claim RAKL is first to provide any one of the following in isolation:

- latent mathematical reasoning;
- task-conditioned similarity / metric learning;
- relational bottlenecks or neural relational reasoning;
- causal abstraction;
- proof graphs / proofs as paths;
- equality saturation or e-graphs;
- proof geometry as a metaphor;
- hidden-space network navigability;
- reachability-aware latent planning;
- proof planning / analogy / rippling;
- model-aware or skill-aware curriculum/data selection;
- external skill compilation into weights/adapters;
- self-improving agents;
- formal verification, provenance, abstention or evidence-based authorization;
- multi-chart/manifold representation by itself.

## Strongest surviving candidate

The potentially distinctive contribution is the **typed conjunction**:

```text
validated QoI/context structural quotient
+ explicit protected/erased-coordinate sufficiency
+ directional StructuralWitness
+ preserved AND non-preserved structure
+ boundary/applicability semantics
+ exact shared structural identities external→training→inference
+ checkpoint-bound learner state
+ verifier-induced operational subject and solvability projection
+ trajectory/certificate separation
+ fresh-assurance model promotion
+ scientific-authority noninterference
```

Even this is a **bounded novelty candidate**, not a priority certificate.

## Evidence rule

For every claimed residual, write:

> Existing RAKL already does X. Strongest external parent already does Y. This experiment adds Z under the same information/compute. The claim is falsified if W.

If this paragraph cannot be made precise, do not run a large experiment and do not write a novelty claim.
