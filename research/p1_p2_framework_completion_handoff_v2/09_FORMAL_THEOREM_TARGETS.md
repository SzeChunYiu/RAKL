# Formal Theorem / Counterexample Targets

These are theorem candidates, not claims until mechanized/proved.

## T1 — Familiarity non-escalation

If an update changes only familiarity/exposure/retrieval metadata and adds no admissible evidence/certificate,

\[
Auth_{t+1}(c)=Auth_t(c).
\]

Plant a countermodel where scalar-confidence systems violate this.

## T2 — Pursuit non-sovereignty

Any finite composition of pursuit-only operators leaves canonical scientific authority invariant.

Generalize existing proposal/derived-view non-escalation to the new Pursuit state.

## T3 — Typed morphism composition

If \(m_1\) and \(m_2\) are licensed and every load-bearing obligation of \(m_1\) is preserved through \(m_2\), the composite may be licensed.
If one obligation is unknown, the composite is not licensed.

Mechanize first on a small exact family.

## T4 — Environment-preserving revision

Revision of assumption/argument state never erases the historical environment that previously supported/refuted a claim; it may mark it defeated/superseded.

## T5 — Decision-sufficiency collision / garbling

The existing projection-collision theorem is the local counterexample.

Strengthen: if \(\pi_2=K\circ\pi_1\) is a garbling and \(\pi_1\) has strictly lower Bayes risk for one registered decision problem, \(\pi_2\) is not sufficient for that class.

## T6 — VOI bounded stopping

For a finite declared probe set and a correct metalevel model, if every available probe has non-positive net VOI, immediate stopping is Bayes-optimal within that bounded metalevel problem.

No open-world/global claim.

## T7 — Single-bias triangulation exclusion

Under declared bias sets, if

\[
\bigcap_{e\in T}B_e=\varnothing,
\]

then no single registered bias mode explains all concordant outcomes.

This is weaker than truth.

## T8 — Topology shortcut soundness

For each registered object family, prove:

topology certificate + local constraints => global validity.

Never state generically for arbitrary scientific structures.

## T9 — Dual-store non-erasure

Schema consolidation never removes or upgrades episode evidence roots:

\[
F_t\subseteq F_{t+1},
\qquad
Auth(C(F_t))=\bot
\]

until external promotion.

## T10 — Negative revival immutability

A new positive successor cannot alter the typed outcome or bytes/hash binding of any predecessor epoch.
