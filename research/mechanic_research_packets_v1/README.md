# Mechanic research packets

This directory contains proposal-only preregistration artifacts for the Paper V–VI RSHEA promotion campaign.

- `PAPER5_PAPER6_SUCCESSORS.json` — frozen fresh successor/revalidation universe from P2 (#573).
- `P3_PROMOTION_ENFORCEMENT_FREEZE.json` — frozen Class-B challenger that makes valid packets a prerequisite for every post-contract promotion candidate.

Historical candidates that predate the packet contract are not retroactively labelled preregistered. Their exact candidate IDs are frozen as `LEGACY_PRE_PACKET` in the promotion gate; any successor/revalidation must use a new candidate ID and a valid packet.

Packet validity grants no scientific or promotion authority. It only permits the ordinary evidence, telemetry, applicability and governance gates to evaluate a post-contract candidate.
