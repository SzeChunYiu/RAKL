# RAKL publishing support

This directory contains publication-production material that should not clutter the reader-facing `publication/` directory.

- `editorial/` — readiness, submission planning, review notes, terminology and author metadata.
- `reviews/` — active external-review solicitation packages.
- `figures/` — shared figure sources and generated build assets.
- `references/` — shared bibliography files.

The public paper packages themselves live under `publication/papers/`. Historical/superseded material is kept separately under `archive/publication/`.
