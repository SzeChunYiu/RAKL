# RAKL Invariant Workflow

## A. Freeze the problem boundary

Record:

```text
object
question/subclaim
decision or QoI
population
scale/horizon
observation boundary
units
allowed evidence
current authority/evidence cutoff
```

## B. Atomize

Decompose the solution chain until each step has one clear semantic job.

Include data and mathematical transformations, not only named models.

## C. Open knowledge fibers

For every unresolved atomic step record alternatives across the standard RAKL dimensions.

## D. Expand knowledge

Search through multiple vocabularies and disciplines. Extract atomic projections, not paper summaries.

## E. Normalize

Build terminology/ontology mappings and representation-equivalence relationships.

## F. Build constrained global paths

Compose only compatible local choices.

## G. Mechanize

Where mechanism matters, derive the effective representation from lower-level building blocks or state explicitly that the model is phenomenological/teacher-only.

## H. Identify

Ask whether observations distinguish the proposed mechanisms. If not, keep an identified/model set or bounds.

## I. Discriminate

Choose the lowest-cost experiment with the highest expected separation or identified-set shrinkage.

Freeze predictions and result branches before native execution.

## J. Validate the validator

Require clean PASS, planted FAIL, and structural CANNOT_CHECK worlds.

## K. Run real/native evidence

Use the same registered population, filtration, target, units, and split across competing candidates.

## L. Read the residual

Do not immediately fit another model. Classify the residual and reopen only plausible generating fibers.

## M. Synthesize

Produce a global object portrait:

```text
facets established
facets uncertain
representation equivalence classes
surviving mechanisms/model set
dependencies among facets
missing dimensions
new derived formalism if justified
```

## N. Review

Run same-context consistency/reflection, then isolated reviewers when independence is required. Freeze reports before synthesis.

## O. Promote narrowly

Promote only claims/method steps supported by their evidence scope.

## P. Recurse

Any new contradiction, failure, missing facet, or method weakness becomes a new RAKL child problem.
