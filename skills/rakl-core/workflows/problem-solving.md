# Workflow — Problem Solving

Use for a new scientific, mathematical, engineering, or modelling problem.

## Procedure

1. Define the object and downstream QoI/decision.
2. Draw the current solution chain as atomic transformations.
3. Open a knowledge fiber for every unresolved step.
4. For each step, enumerate alternative representations, mechanisms, assumptions, observations, scales, inference methods, and falsifiers.
5. Search alternative vocabularies before assuming the known taxonomy is complete.
6. Collapse exact/equivalent representations.
7. Remove incompatible combinations.
8. Construct candidate mechanism paths from fundamental building blocks to the downstream QoI.
9. Identify what observations cannot distinguish.
10. Choose discriminators for the remaining ambiguity.
11. Validate on controlled worlds before native evidence.
12. Use residuals to recurse.
13. Synthesize a global object portrait and, only if required, derive a new formalism that contains surviving prior descriptions as projections/special cases.

## Required question at every step

> What aspect of the object does this step preserve, and what does it throw away?

## Failure rule

If all models fail, do not immediately broaden model complexity. Reopen source, observation, target, identifiability, decomposition, and scale fibers first.
