# Workflow — Literature Absorption

Use for papers, repositories, books, standards, datasets, or other knowledge sources.

## Goal

Do not produce a flat bibliography. Convert sources into projections on a shared object and measure semantic lattice gain.

## Search rounds

For each unresolved fiber child, search:

1. exact/foundational theory;
2. impossibility, counterexample, and failure literature;
3. newest primary research;
4. adjacent mathematical/scientific domains;
5. deliberately alien domains with the same formal structure;
6. alternative vocabularies and notation;
7. citation ancestry and influential descendants when useful.

## Atomic source record

Extract:

```text
source_id
object
facet(s)
projection/claim
mathematical object
mechanism interpretation
context tuple
assumptions
scale
observation model
method/inference
evidence level
uncertainty
counterexample/falsifier
data requirement
what this projection cannot see
mapping to existing lattice
QoI/decision implication
```

## Semantic gain

A source is high-value when it adds a retained:

```text
facet
representation class
mechanism
assumption
scale law
identifiability condition
counterexample
falsifier
error/remainder
data source
decision implication
```

A source that only repeats an existing object can strengthen provenance/evidence without increasing lattice dimensionality.

## Deduplication

Deduplicate identifiers and then deduplicate **meaning**.

Map new claims to:

```text
new facet
new member of existing facet
equivalent representation
contextual refinement
contradiction
corroboration only
analogy only
```

## Archive rule

New discoveries enter raw storage first. Promotion into canonical knowledge requires normalization, compatibility review, and evidence authority.
