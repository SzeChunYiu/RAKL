\section{Current strict promotion path and remaining external trust roots}
\label{sec:strict-current-promotion}

The versioned implementation has been hardened beyond the original architecture described above.  Historical classifiers and proof-DAG APIs remain available because their negative and superseded states are part of the research record, but they are not the current closure-eligible promotion path.  The strict current path is the conjunction
\[
\begin{gathered}
\text{content-addressed assurance}
\;\land\;
\text{exact proof-dependency manifest agreement}
\\[2ex]
\;\Longrightarrow\;
\text{candidate eligibility only}.
\end{gathered}
\]
It does not itself grant theorem, novelty, research-value, scientific or publication authority.

\paragraph{Content-addressed assurance.}
The strict assurance successor binds the current proposer, the exact informal/formal statement pair, the complete novelty dossier and literature-world manifest, the value-review procedure, the proof source and checker manifest, and an independent verifier attestor.  Load-bearing actor, procedure, statement, proof, novelty and manifest identities are lowercase SHA-256 content digests rather than human-readable labels placed in fields named ``hash''.  A review receipt issued against another proposer, a change of informal intent under the same formal statement, a post-review novelty-result change, proposer self-review, verifier self-attestation, and label-like identities all fail closed.

\paragraph{Proof-DAG dependency integrity.}
The strict checkpoint path additionally requires a dependency-manifest receipt for the exact proof source.  The manifest identity, extractor/\allowbreak procedure identity, theorem statement and every dependency statement are content-addressed.  Its transitive dependency-statement set must equal the ProofDAG closure exactly: omitted, extra and source-swapped dependencies are rejected.  Equality of two locally supplied sets does not prove that an external extractor faithfully parsed the proof source; that correspondence is an explicit provenance trust root rather than something this system self-certifies.

\paragraph{Executor independence.}
The same exact evidence artifact is classified through this promotion contract independently of whether its proposer is an LLM or a substantially different symbolic/enumerative executor.  This is an invariance claim about authority semantics, not a claim that the executors have equal theorem-discovery performance.  Self-review remains blocked regardless of proposer class.

\paragraph{What is still external.}
A concrete new-mathematics claim still requires an actually executed, cutoff-scoped literature search; independent mathematical and value review whose real-world identities are externally attested to the recorded manifests; and a concrete proof whose proof-source/dependency extraction is independently grounded.  A field-facing discovery-performance result additionally requires a frozen public/open task epoch, valid-promotion recall alongside false-promotion rate, and fully costed strongest proof-search parents.  These obligations cannot be replaced by local conformance tests or by the fact that the strict software path itself is green.
