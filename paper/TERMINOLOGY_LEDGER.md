## Notation locks

- `K_t` = epistemic scientific state.
- `mathfrak R_t` = functional researcher state.
- `Omega_t` = research/method operator repertoire.
- `mathcal G_t` = research agenda when used inside `mathfrak R_t`.
- `mathcal G_t^K` = protected governance/evaluator coordinate inside `K_t`.
- `alpha(c)=(G,R,M,I,D)` = scientific authority certificate tuple.
- `gamma` = scientific context; avoid using it for an LLM generation parameter.
- `tau=(q,alpha*,gamma)` = scoped scientific target when target-path notation is needed.
- `Delta_D` = development improvement for method evolution.
- `Delta_A` = fresh-assurance improvement.
- `Delta_joint=min(R_D,R_G)-R_DG` = quant-finance joint predictive bridge estimand.

## Claim-language locks

Preferred:

- “candidate methodology” before prospective real-world results exist;
- “scoped”, “registered”, “under the declared evidence/observation class”;
- “supports”, “is consistent with”, “partially identifies”, “fails to distinguish”;
- “software-contract validated” for known-answer unit/CI evidence;
- “prospective” or “preregistered” for unexecuted headline experiments.

Avoid unless directly supported:

- “proves the true mechanism”;
- “complete scientific understanding”;
- “universally optimal”;
- “autonomously discovers all weaknesses”;
- “independent review” for same-context role simulations;
- “scientifically validated” when only software/known-answer tests ran.
