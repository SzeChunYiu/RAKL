# Author metadata required before submission

The repository cannot infer or invent personal publication metadata. Before submission, supply the following once and bind it consistently across all four papers:

- author affiliation(s);
- corresponding-author email;
- ORCID, if you want it displayed;
- funding statement, including an explicit “no specific funding” statement if accurate;
- competing-interests declaration;
- acknowledgements;
- data-availability statement appropriate to each paper;
- code/materials-availability statement appropriate to each paper;
- preferred license for public preprints/source packages.

Language-model assistance is already disclosed where present in the manuscripts and must remain represented as tool assistance rather than authorship.
