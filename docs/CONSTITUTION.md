# RAKL Constitution

RAKL is self-improving, but self-improvement must not dissolve the principles that make its evidence trustworthy.

This document distinguishes **constitutional invariants** from **replaceable method modules**.

## I. Constitutional invariants

The following are the current core philosophy.

1. **Object before answer.** Define the object, decision/QoI and context before comparing solutions.
2. **Projection before competition.** Sources usually provide contextual views of an object, not complete rival theories.
3. **Context before contradiction.** Align population, scale, observation model, units, assumptions and intervention before declaring conflict.
4. **Recursive atomic decomposition.** Every unresolved transformation may open its own knowledge fiber.
5. **Normalize before multiplying.** Terminology and representation equivalence are resolved before expanding the combinatorial theory space.
6. **Compatibility before testing.** Structurally impossible combinations are pruned before empirical model search.
7. **Representation is not mechanism.** Predictive fit does not by itself identify a microscopic cause.
8. **Mechanism requires ancestry.** Mechanistic authority requires a trace from building blocks through interactions and coarse variables to downstream effects.
9. **Residuals are information.** Failure reopens the fiber dimensions capable of producing it.
10. **Discriminate rather than decorate.** Prefer experiments and queries that separate surviving explanations.
11. **Known-answer and hostile worlds precede native authority.** A validator must demonstrate that it can pass, fail and cannot-check.
12. **Negative evidence is immutable history.** Nulls and refutations are not erased by successors.
13. **LLM proposes; evidence governs.** Model confidence never substitutes for evidence or identifying assumptions.
14. **Same-context reflection is not independent review.** Independence is an experimental property, not a writing style.
15. **Raw discovery does not auto-promote canonical knowledge.** Promotion is a separate governed step.
16. **Saturation is semantic novelty after deduplication, not paper count.**
17. **Knowledge saturation is distinct from problem closure.** A fiber can be saturated and still blocked or unresolved.
18. **RAKL applies recursively to RAKL.** Method steps can be challenged using the same evidence discipline.

## II. Replaceable method modules

These are expected to evolve aggressively:

- problem decomposition heuristics;
- workflow routing;
- search query generation;
- source-routing and fallback order;
- claim extraction;
- ontology normalization;
- representation-equivalence detection;
- contradiction diagnosis;
- experiment/query selection;
- reviewer allocation;
- memory and context compression;
- semantic novelty estimation;
- saturation heuristics;
- software implementation;
- benchmark suites;
- prompt/program optimization.

A better challenger may replace any of these after frozen evaluation.

## III. Amendment classes

### Class A — implementation change

Examples: parser, schema, caching, UI, indexing.

May be promoted automatically after tests and backward-compatibility checks.

### Class B — workflow/heuristic change

Examples: new search router, new decomposition policy, tree-search scheduler, different reviewer allocation.

May be promoted automatically when:

- evaluation tasks were frozen first;
- incumbent and challenger run on the same task packet;
- hard evidence invariants remain satisfied;
- challenger improves at least one registered meta-QoI without violating blocking meta-QoIs;
- trial and cost accounting are preserved.

### Class C — constitutional change

A proposal that weakens, removes or materially redefines a constitutional invariant.

Class C changes **must not be silently self-merged by the same LLM that proposed them**.

Required evidence:

1. the invariant being challenged;
2. a concrete failure/residual caused by that invariant;
3. alternative formulations from multiple independent source traditions;
4. a frozen benchmark containing cases where the old and new principles make different predictions or decisions;
5. at least one isolated adversarial review;
6. explicit scope and rollback plan;
7. a human-visible amendment receipt.

The default is to improve the picture by adding coordinates or scope, not by deleting evidence safeguards.

## IV. Self-improvement objective hierarchy

RAKL must never optimize one scalar research score blindly.

Blocking meta-QoIs:

```text
groundedness
non-fabrication
causal/decision-time legality
known-answer correctness
negative-result preservation
reproducibility
scope/authority honesty
```

Non-blocking optimization objectives include:

```text
semantic recall
false-novelty reduction
contradiction detection
missing-facet discovery
information gain per cost
time/token/compute efficiency
quality of mechanism derivation
quality of downstream decisions
```

Efficiency cannot compensate for a blocking validity failure.

## V. Direct-to-main automation rule

An automated self-RAKL run may commit directly to `main` only for Class A/B changes that:

- preserve all constitutional invariants;
- include a machine-readable research/change receipt;
- add or update tests for changed behavior;
- pass the available test suite and exact local/CI checks accessible to the run;
- do not rewrite historical evidence;
- record semantic novelty and remaining uncertainty.

If these conditions are not met, the run records the residual/proposal without changing the active method behavior.
