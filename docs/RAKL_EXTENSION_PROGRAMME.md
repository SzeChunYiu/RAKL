## Purpose

Coordinate optional RAKL extensions identified through framework review, cognitive-science/philosophy research, and application feedback from `RAKL_math`, so future sessions **extend RAKL** rather than redefine it around a single metaphor or operator.

Governing rule:

> **Extend RAKL; do not redefine RAKL around any single new metaphor or operator.**

Current v3 persistent-state, authority, failure, gluing, saturation, and Self-RAKL contracts remain in force unless a separately evaluated challenger earns promotion under the existing Self-RAKL / fresh-assurance gates.

## Required evaluation order

Avoid integrating all extensions simultaneously.

### Phase 0 — Preserve incumbent

- Current RAKL remains authoritative.
- No rename or runtime behavior change grants itself promotion.
- Freeze exact framework/application baselines before challenger comparison.

### Phase 1 — Atomic known-answer benchmarks

Evaluate each extension separately on solved/known-answer tasks:

```text
E1 associative retrieval
E2 backward + seeds
E3 route planning
E4 breakthrough control
E5 review diversity
E6 route-health diagnostic
```

Include null/harmful controls. Preserve negative results.

### Phase 2 — Composition benchmarks

Only after atomic signal exists, test combinations such as:

```text
saturation -> E2
saturation -> E1
route-health -> E4
E1 -> E2 connection test
E5 -> E4 representation reset
```

Measure interaction effects and overhead.

### Phase 3 — Historical source-blind `RAKL_math` replay

Use existing episodes only as retrospective method evidence. Ask whether an extension would have retrieved earlier, detected a root-interface gap earlier, avoided repeated route families, found a useful alternative representation, reduced false/local progress, or preserved productive persistence.

No retrospective replay receives prospective discovery authority.

### Phase 4 — Fresh proposal/shadow application trials

Run on genuinely fresh `RAKL_math` atoms with preregistered extension triggers, baselines, and metrics.

### Phase 5 — Self-RAKL promotion

Only positive fresh evidence can support a challenger through protected Self-RAKL evaluation/governance. Same-session critique is not independent review. Do not weaken Constitution, protected evaluators, or frozen falsifiers to obtain a pass.
