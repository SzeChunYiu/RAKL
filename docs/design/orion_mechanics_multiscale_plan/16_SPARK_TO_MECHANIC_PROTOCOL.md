# Spark-to-Mechanic Protocol

This is the formal interface for “random ideas.”

Random ideas are useful because they can reveal an unseen mechanism family. They become dangerous only when analogy skips falsification.

## Stage S0 — Spark

Example:

> Lightning seems to find a path almost instantly. Can Orion do something equivalent?

Record exactly, without defending it.

## Stage S1 — Physical/conceptual correction

Ask:

```text
What is actually happening?
Which part is observation?
Which part is metaphor?
Which part is false?
```

For lightning:

- stepped propagation;
- branching;
- local field dependence;
- evolving conductivity;
- no demonstrated generic precomputed shortest path.

## Stage S2 — Atomize mechanism

Extract candidates:

```text
GLOBAL_FIELD
LOCAL_GRADIENT
BRANCHING_FRONT
THRESHOLD_GROWTH
CONDUCTANCE_REINFORCEMENT
PATH_CONCENTRATION
MULTISCALE_STRUCTURE
```

## Stage S3 — Parent envelope

Search multiple families, not one nearest analogy.

## Stage S4 — Failure envelope

For each parent ask:

```text
what does it require?
where does it fail?
what cost is hidden?
what is domain-specific?
what would be circular in Orion?
```

## Stage S5 — One dimension higher

Build a coordinate table.

Example:

```text
path enumeration
field construction
representation lift
adaptive feedback
branching
multiscale
verification
```

Locate parents as points.

Search missing/composable cells.

## Stage S6 — Orion delta

State the non-duplicate delta.

For the lightning spark:

> Search over representations that induce a solvability field whose local direction predicts verified global progress; use branching/conductance dynamics for exploration, while preserving explicit decode and authority gates.

This is much more precise than “lightning search.”

## Stage S7 — Cheapest falsifier

Before building a large system ask:

```text
What tiny world would make this obviously fail?
```

Examples:

- field construction cost > baseline search;
- local field has false attractor;
- representation only works with answer leakage;
- branching explodes;
- identity representation dominates;
- A* dominates.

# Why this is important

The project should maximize **idea throughput** while minimizing **metaphor lock-in**.

The ideal culture is:

```text
wild spark
+
hard correction
+
whole-parent-family learning
+
higher-dimensional synthesis
+
cheap refutation
=
useful Orion evolution
```
