# Paper Insert — Cumulative Validated Method Acquisition

Status: publication drafting support. Runtime contextual-frontier routing remains prospective.

## Motivation

A scientific research system that learns from other frameworks should not import whole architectures or concatenate every attractive component. External systems embody useful local operators under different assumptions, resource envelopes, task contexts and epistemic semantics.

RAKL therefore treats a research method itself as a contextual chart in a method atlas.

## Candidate method state

For atomic research fiber `f`, an operator is represented as

\[
m=(f,\gamma,A,I,O,R,\alpha^+,\alpha^-,E,F,C),
\]

encoding context, assumptions, interfaces, resources, permitted/prohibited authority, validation evidence, negative history and cost/performance coordinates.

Two methods enter direct competition only if their registered comparison coordinates are compatible or connected through an explicit transition witness. Otherwise the methods remain parallel local views.

## Validity-gated frontier

Within a compatible scope, RAKL first applies blocking scientific-validity constraints. Only methods that satisfy those constraints enter non-blocking multiobjective comparison. A local non-dominated set can then represent quality/cost tradeoffs.

This means that a cheaper or higher-scoring method cannot dominate another method by sacrificing groundedness, causal legality, known-answer correctness, reproducibility, negative-history preservation or authority honesty.

## Relationship to prior work

Pareto selection of evolved agent programs, held-out skill validation, scientific skill mining and procedural ability-transfer evaluation already exist in recent agent-evolution systems. RAKL therefore does not claim those mechanisms as inventions.

The candidate distinction is the integration of:

```text
atomic scientific-method decomposition
context/assumption comparability
scientific authority envelopes
blocking validity before optimization
non-forced coexistence of incompatible useful methods
negative/supersession history
evidence-governed promotion
bounded-context materialization
```

## External learning

An external framework can contribute one or more atomic operators. After normalization and evaluation, an operator may replace a local incumbent, add a complementary frontier point, deduplicate as equivalent, remain a parallel local method, or fail closed.

Thus cumulative learning does not require a single monolithic super-agent. The system accumulates a **validated contextual repertoire**.

## Empirical falsifier

This structure earns empirical credit only if it improves scientific-process outcomes relative to simpler alternatives. The prospective experiment must compare global Pareto selection, static curation, uncontrolled aggregation and RAKL contextual assimilation under matched resources.

If simple global selection achieves equal epistemic validity, transfer and cost, the extra contextual/authority structure should be demoted rather than defended rhetorically.
